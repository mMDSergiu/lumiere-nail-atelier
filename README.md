# Lumière Nail Atelier: website, Nail Design Studio and salon editor

A nail salon website with a built-in **online nail design studio**. It has three languages
(English, Română, Русский), a light and a dark theme, online booking through **Masters Salon**,
and a **salon login** where the owner edits texts, prices, photos and the team.

## How to open it

| What you want | Do this |
|---|---|
| **Run the full website (with salon login)** | Double-click `start.bat`. It installs and builds everything, then opens http://localhost:4321 |
| **Just look at it, no editing** | Open `dist/website/index.html` (double-click). The salon login needs the server, so it doesn't work this way. |
| **Work on the code with live reload** | `npm run dev` → http://localhost:5173 (the salon login works here too) |
| **Rebuild after code changes** | `npm run build` |

## Salon login (editing the website)

1. Scroll to the bottom of the page and click **Salon login** (or open `/#admin`).
2. Sign in. A bar appears at the bottom of the page. Click **Edit website**.
3. The editor has six tabs: **General** (name, phone, address, main photo), **Texts** (every text on the
   page, in each language), **Prices** (services), **Gallery** (photos of your work), **Team** and **Booking**.
4. Changes show on the page right away. Click **Save** to publish them, or **Discard** to undo.

Change the login: `npm run set-password -- <username> <password>`, then restart the server.
Only the username and a secure hash of the password are stored, in `.env` (never commit it).

Saved content and photos are kept in `data/` (`content.json` and `uploads/`). **Back this folder up.**
Delete `data/content.json` to go back to the original content.

## Online booking with Masters Salon

Masters Salon has no public API, so the website uses your **Masters online booking page**. That page
already uses your real calendar: free slots, days off, breaks, each master's hours. Every booking lands
straight in the Masters app, and a time booked in the app disappears from the page.

1. In the Masters Salon app, open the online booking settings and copy your booking page link.
2. On the website: **Salon login → Edit website → Booking**, paste the link, then click **Save**.
3. Choose how it opens:
   - **New tab** works everywhere.
   - **Inside the website** opens it in a window over the page, if Masters allows that.

   Each team member can also have a personal booking link.

Without a link, the website shows a **request form** instead. It is not connected to email yet.

## Hosting it online
The website needs a host that runs **Node.js 20+** (for example Render, Railway, Fly.io or a small VPS):
`npm install && npm run build && npm start`. Set `ADMIN_USER` and `ADMIN_PASSWORD_HASH` (from `.env`),
optionally `PORT` and `DATA_DIR` (a folder that is kept between deploys). Use HTTPS.

## Embedding the studio on another website
```html
<script src="nail-designer.iife.js"></script>
<nail-designer salon-name="Your Salon" accent="#9f4e5e" lang="ro" theme="light"></nail-designer>
```
| Attribute | What it does |
|---|---|
| `salon-name` | Shown in the studio and as the heading of the exported image |
| `accent` | Brand color |
| `lang` | `en`, `ro` or `ru` |
| `theme` | `light` or `dark` |

CSS variables: `--nd-height`, `--nd-height-mobile`, `--nd-font`, `--nd-bg`, `--nd-surface`, `--nd-radius`, `--nd-border`.

```js
const el = document.querySelector('nail-designer');
el.addEventListener('nail-design-finish', (e) => { e.detail.image; e.detail.design; });
el.getDesign(); el.setDesign(json); el.toDataURL();
el.previewImage(design, 600, 700, '#faf4f1'); // hand picture of any design
el.nailImage(design, 1, 220, 420);            // close-up of one nail
```
