# UI / UX

- Mobile-first: clients and staff mostly use phones. Check about 390px width.
- Booking must be fast: few taps, no forced sign-up. The Masters booking page handles the actual booking.
- Accessible: readable contrast in **both** themes (aim for 4.5:1 for text), tap targets of at least 40px,
  labels and aria for icon buttons, focus trap in modals, Esc closes them.
- Style: calm, elegant, beauty-industry look. Serif headings (Cormorant Garamond), Jost body, rose #9f4e5e +
  champagne gold, arch-shaped image frames, generous spacing, soft scroll reveal.
  Never write "demo"; it must look like a finished product.
- Languages: EN / RO / RU everywhere (site, studio, editor). Texts must be natural, not literal translations.
- Dark theme: evening palette (#141012 background, light rose accents); the studio follows via `theme`.
- The salon editor must stay simple for a non-technical owner: plain words, live preview, clear Save/Discard,
  a two-click delete.
